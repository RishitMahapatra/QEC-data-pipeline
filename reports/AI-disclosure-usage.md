# AI USAGE THROUGHOUT THE PROJECT

## 1. What we used AI for

1. We used AI to understand quantum-related concepts. We learnt about these
   concepts from different sources (like blogs, YouTube videos, Wikipedia,
   the provided README files, etc.), including LLMs, to get a
   proper understanding of the concepts and what the assignment is about.
2. We identified gaps and drafted stage-wise checklists by comparing them
   with the requirements and rubrics, so we had a clear direction to work
   towards.
3. We used it to help structure and draft written explanations (design
   decisions, reports) once the team had already made the technical
   decisions. It helped understanding how to set up the data processing pipelines for the Bronze and Silver stages.
4. We also got general coding assistance where useful, and the team
   reviewed and understood it rather than using it blindly.   
5. We used it to help understand certain concepts from the datasets and data structures to map them better to the assignment requirements.
6. It sometimes helped brainstorm schema designs and check SQL syntax for the Gold stage.

## 2. How did we use AI responsibly?

1. The AI-generated output served as a template rather than a final
   answer. We cross-checked it against the course's own spec documents.
2. We tested or ran anything AI helped produce ourselves before trusting
   it.
3. We spent time discussing in group and understanding the reasoning rather than just copying conclusions.
4. We also made sure that we understood everything that was generated and we prioritized discussions with the group when something was not clear.
