# AI USAGE THROUGHOUT THE PROJECT

- CODING : human in the loop while understanding the whole architecture in depth

- Understanding QEC concepts and how to organize the project itself ( this was essentially done through the weekly group meetings).

- REPORTS: Structuring ideas to be as clear as possible


## Rishit's Version of AI usage disclosure

## 1. What we used AI for

1. We used AI to understand quantum-related concepts. We learnt about these
   concepts from different sources (like blogs, YouTube videos, Wikipedia,
   the provided README files, etc.), including LLMs (Claude), to get a
   proper understanding of the concepts and what the assignment is about.
2. We identified gaps and drafted stage-wise checklists by comparing them
   with the requirements and rubrics, so we had a clear direction to work
   towards.
3. We used AI to help structure and draft written explanations (design
   decisions, reports) once the team had already made the technical
   decisions.
4. We also got general coding assistance where useful, and the team
   reviewed and understood it rather than using it blindly.

## 2. How did we use AI responsibly?

1. The AI-generated output served as a template rather than a final
   answer. We cross-checked it against the course's own spec documents.
2. We tested or ran anything AI helped produce ourselves before trusting
   it.
3. We spent time discussing and understanding the reasoning rather than
   just copying conclusions.

## Khushi's Version of AI usage disclosure (QASMBench - Bronze, Silver, Gold Stages)

## 1. What we used AI for

1. We used AI to help understand certain QASMBench concepts and data structures to map them better to the assignment requirements.
2. We used AI for general coding assistance and reference when setting up the data processing pipelines for the Bronze and Silver stages.
3. We used AI to help brainstorm schema designs and check SQL syntax for the Gold stage.
4. We used AI to help structure and polish written explanations for our design decisions and reports.


## 2. How did we use AI responsibly?

1. The AI-generated output served as a template rather than a final answer. We cross-checked it against the course's own specification documents and the QASMBench schema.
2. We spent time understanding the reasoning behind the AI's suggestions rather than blindly copying the code or conclusions.
